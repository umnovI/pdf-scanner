# Сканер PDF — правила для работы над репозиторием

- Перед созданием PR и перед каждым пушем в открытый PR запускать `/code-review`
  на изменениях, исправлять найденные ошибки и только потом пушить / открывать PR.
  Находки, которые сознательно не исправлены, перечислить в описании PR с причиной.
- Каждый новый PR — от свежего `main`; слитые ветки не переиспользовать.
- Приложение — чистый HTML/CSS/JS в `app/`, без внешних библиотек и сборки.
- Перед PR проверять в браузере (Playwright, эмуляция телефона): съёмка/галерея →
  редактор → PDF, без ошибок в консоли.
- Ответы пользователю и тексты интерфейса — на русском.
