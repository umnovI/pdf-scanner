# Сканер PDF

Приложение для телефона: фотографируете документы (или берёте фото из галереи),
обрезаете и выравниваете, сохраняете всё одним PDF.

Это веб-приложение (PWA): открывается в браузере и устанавливается на главный экран
как обычное приложение. Работает без интернета, фото никуда не отправляются —
вся обработка идёт на самом телефоне.

## Возможности

- Съёмка обычной камерой телефона (кнопка «Готово и снять ещё страницу» — для многостраничных документов, «Переснять» — заменить неудачный снимок) или выбор фото из галереи
- Автоматический поиск краёв листа — по яркости и по цвету, так что находятся и цветные листы (жёлтые грамоты, тетради в клетку, бланки); ручная подстройка углов с лупой
- Выравнивание перспективы (лист, снятый под углом, становится ровным прямоугольником)
- Фильтры: Оригинал, Улучшить (контраст без изменения цвета бумаги), Цветной лист (убирает тени, сохраняя цвет бумаги и печатей), Серый, Документ (белый фон, убирает тени), Ч/Б
- Поворот, порядок страниц, удаление
- PDF: **все страницы одного размера** (A4 или Letter, книжная ориентация); фото растягивается на всю страницу или вписывается без искажений; поля; три уровня сжатия
- «Поделиться» (в мессенджер, почту, на диск) или «Скачать»
- Страницы сохраняются в браузере и не пропадают при перезагрузке

## Как поставить на телефон

1. Откройте адрес приложения (GitHub Pages: `https://<владелец>.github.io/pdf-scanner/`).
2. **Android (Chrome):** меню ⋮ → «Добавить на главный экран» / «Установить приложение».
   **iPhone (Safari):** кнопка «Поделиться» → «На экран „Домой“».

## Обновления

При каждой публикации workflow вписывает номер коммита в `sw.js` и `app.js`, поэтому
у каждой версии свой номер. Приложение проверяет обновление при запуске, при возврате
из фона и раз в час. Когда новая версия загружена, сверху появляется плашка
«Вышла новая версия → Обновить», отсканированные страницы при этом сохраняются.
Текущая версия написана внизу окна «Сохранить PDF».

## Публикация

Workflow `.github/workflows/pages.yml` выкладывает папку `app/` на GitHub Pages при каждом
пуше. Если Pages ещё не включён: Settings → Pages → Source: **GitHub Actions**.

## Запуск локально

```sh
cd app
python3 -m http.server 8000
# открыть http://localhost:8000
```

Камере и установке нужен HTTPS (или localhost).

## Зависимости

- **Для работы приложения:** никаких. Чистый HTML/CSS/JavaScript, без внешних библиотек.
  Нужен современный браузер (Chrome/Edge/Samsung Internet на Android, Safari 15+ на iOS).
- **Для локального запуска:** любой статический веб-сервер, например Python 3 (`http.server`).
- **Для перерисовки иконок (необязательно):** Python 3 и Pillow (`pip install Pillow`),
  скрипт `tools/make_icons.py`.

## Устройство

| Файл | Что делает |
| --- | --- |
| `app/index.html`, `app/style.css` | Интерфейс |
| `app/app.js` | Логика: страницы, редактор, окно PDF |
| `app/imgproc.js` | Обработка: поворот, перспектива, фильтры, поиск краёв |
| `app/pdf.js` | Сборка PDF (JPEG вставляются без перекодирования) |
| `app/db.js` | Хранение страниц в IndexedDB |
| `app/sw.js`, `app/manifest.webmanifest` | Офлайн-режим и установка |
